# 🛡️ 랜드마크 수호대 (Landmark Defenders)

세계 각 도시의 랜드마크를 나쁜놈들로부터 지켜내는 모바일 친화 슈팅 게임입니다.

## 규칙
- 나는 랜드마크 바로 앞에서 싸우고, 나쁜놈들은 **나와 랜드마크**를 공격합니다.
- 도시마다 **3단계**의 적이 몰려옵니다. 제한 시간(**1~3분**) 안에 전부 물리치면 방어 성공!
- 방어에 성공하면 다음 도시로 이동: 서울(N서울타워) → 파리(에펠탑) → 런던(빅벤) → 뉴욕(자유의 여신상) → 카이로(피라미드)
- ⚠️ 예외상황: 랜덤으로 **거대한 적 2명**이 갑자기 나타납니다.
- 내 체력 또는 랜드마크 체력이 0이 되거나 시간이 끝나면 실패 → 결과와 **다시하기** 버튼 표시

## 조작
- 모바일: 화면 드래그로 이동, 사격은 자동, 💥 폭탄 버튼
- PC: 방향키/WASD 이동, 스페이스 = 폭탄, Enter = 버튼 선택
